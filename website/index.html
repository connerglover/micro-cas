Why use two storage locations?

CAS is a small source launcher, so it goes to RAM and appears in Python. The libraries are compiled EVO modules (.8mp2), stored in archive and imported as needed. This avoids compiling the engine on the calculator. Imported code still needs working memory; archive is not extra RAM. Ordinary archived .py files are not a substitute.

My calculator isn’t in the list.

Turn it on and use a USB cable that supports data. Close TI Connect and other calculator tabs. In Chrome or Edge, select the TI-84 EVO serial port when prompted. This installer supports the EVO and EVO-T, not the TI-84 Plus CE.

A transfer stopped. What now?

Keep any files that arrived. Reconnect, then install again: the same MicroCAS filenames are replaced. If you stopped the transfer yourself, choose Install again. If the connection timed out, reload this page first. Wait for archive verification before running CAS.

What happens to an earlier version?

Earlier versions, including those released as cas-evo, are recognized. The new version uses far fewer files. The installer reads the calculator’s file list once, deletes every Python file named after an earlier MicroCAS file that the new version no longer uses, and replaces the rest. Rename your own programs first if one shares a MicroCAS name (CAS, or a name starting with CAS or CV). Your other programs stay untouched.

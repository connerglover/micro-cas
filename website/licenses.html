Built with open tools.

The installer connects directly from your browser to your calculator. It uses the following pinned components. Connection logs and calculator contents stay in your browser.

WebTILP

WebTILP and tilibs provide the USB/serial connection and EVO protocol. This build uses revision 06d60cb, distributed under the GNU General Public License, version 2 or later.

Download corresponding source and dependency archives. The archive includes the pinned upstream build scripts, patches and dependency licenses. Build revisions, dependency versions and source checksums are available separately.

TIVarsLib

TIVarsLib converts and reads EVO Python files. Copyright 2015–2026 Adrien “Adriweb” Bertrand; MIT license. Its source is included in the source download above.

MicroCAS installer

The browser integration is distributed under the GNU General Public License, version 2 or later. Download the integration source and build scripts. This license applies to the website integration; it does not change the calculator engine’s licensing.

Public Sans

Public Sans is self-hosted, with no external font requests. It is provided under the SIL Open Font License.

Hardware checks

Software checks cover package integrity, file conversion, native Python execution and the installer’s transfer sequence. They do not establish that this particular package has run successfully on a physical EVO. After installation, run CAS in a fresh Python session.

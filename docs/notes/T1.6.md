## Public API as implemented (§21.2)

- **`go(job)` [1]**: `job` is `('eval', text)` or `('form', hist index)`. Returns a record
  `(kind, text, approx, flags)`; never raises except `KeyboardInterrupt`, re-raised after the
  reset. On every path: drop generators, clear `NEEDED`/`LIVE`/`PINNED`, `K.reset()`, then
  `evict_all()` after OOM or `trim()` otherwise, then the message, then `finish`.
  - The trampoline is the §10.4 sketch: `yield g` (virtual call), `yield scoped(g)` (region,
    `K.keep` on return), `yield TICK`, `yield value` (return), bare return / `CasSoft` -> `None`
    (`LASTSOFT[0]` keeps the exception), `MAXGEN = 64` (`expression too complex`),
    `BUDGET = 20000` steps (`too long`), cancel `K.ESC()` every 32 steps (`Interrupted`),
    `BUSY(steps)` every 512.
  - A root that returns `None`: the message of its `CasSoft` if it has a str arg, else
    `undefined`.
- **`start(job)` [2]** -> `(code, ctx)`, or `(None, message)` for purge and definitions. Applies
  §7.1 stages 1-2 and the §7.9 rules, then the preload (below). `ctx = [deg, None, 0, inert]`.
- **`finish(job, rec)` [2]**: after the reset. Eval jobs only: the rule 2-3 store, `ANS`,
  `HIST`. It ORs the runner's `FLAGS` into an answer record's flags, so `F_PLUSC`, `F_DEG`,
  `F_SOLN` survive whatever the printer returns.
- **`msg_rec(err)` [2]**, **`need(key)` [3]**, **`drop(keys)` [3]**, **`evict(f)` [4]**,
  **`trim()` [2]**, **`evict_all()` [2]**, **`scoped(g)` [7]**, **`okname(v)` [7]**.
- **Registry:** `CMDS ALIAS MACROS HINT` (§15.1; `approx`/`evalf` are not commands, T1.5;
  `arclen` is `(4, 5, None)`; `HINT` also has the macros, `purge`, `approx`).
- **Loader tables:** `DEPS DEV PARTS FAMILY CLOSURE COST LINES PEAKB FRAG` as module-level
  literals; `DEV/PARTS/FAMILY/CLOSURE` equal `bundle.desktop_tables(manifest, DEPS)` (tested).
  `COST`/`LINES` are empty on the desktop (`need` uses `.get(p, 0)`); the bundler fills them.
  `EVDICT = 0` (`1` = manifest `EVICT 'dict'`: `m.__dict__.clear()` before the delete).
  `KEEPFREE = 40960`.
- **Loader state:** `MODS LOADED USE CLOCK PINNED LIVE NEEDED`. Hooks: `MEMFREE = None
  #@native`, `BUSY = None` (conftest fills both on the desktop; `None` is tolerated).
- **Session:** `ANS HIST VARS FUNCS SET` (§7.11); `HIST` entries `[input, output, kind,
  approx, flags, forms]`, at most `HISTMAX = 40` and `HISTTEXT = 8192` characters.
- **The running command** (module globals, for the printer / CVFORM): `LINE` (input after
  autoclose), `CTX`, `FLAGS`, `TARGET`.
- **Records:** kinds `R_ANS = 'ans'`, `R_MSG = 'msg'`; flags `F_PLUSC 1`, `F_PURGEHINT 2`,
  `F_APPROX 4` (printer), `F_DEG 8`, `F_SOLN 16` (= `P.F_SOLN`). `printer.py` (T1.7) uses the
  same names and bits.
- **The printer call:** `PR.record(val, (job kind, LINE, ctx, FLAGS))`. T1.7's `record`
  implements exactly this.

## The §7.9 rules as implemented

0. `purge(n1, ...)`: checked on the **stage-3** tokens, so names are whole (`purge(ab)` never
   becomes `a*b`). Message `a, f purged`. Any other shape: `invalid use of purge`.
1. `f(x, ...) := body` (stage 4 writes `:=`): `f` must pass `okname`; params are distinct
   `okname` names other than `f` (else `invalid assignment`); the body is `rpn`-checked now
   and stored unexpanded as `P.untok(body)`. Defining `f` deletes `VARS[f]`, storing `f`
   deletes `FUNCS[f]`. Message `f(x) defined`.
2. `expr => name` at the first top-level `=>`; the target must be the last token and pass
   `okname`, else `Invalid variable name`.
3. `name = expr` / `name := expr`, `okname(name)`, no top-level comma (`y=1,2` is a list), and
   `name` not among the **typed** rhs tokens (FlowCE's selfref test on the unevaluated parse).
   Otherwise the whole line is expanded and evaluated (`x=x+1` with `x` stored is `false`).
4. A lone `=` (last RPN item) with exactly one unknown `s` name (not in `P.CONSTS`): the
   runner appends `('s', x)` and `('F', 'solve', 2)` to the RPN.
6. `+C`: the line starts with an `integrate(`/`int(` call with at most one top-level comma
   (FlowCE `is_antideriv`, a prefix test).

`okname`: `[a-z][a-z0-9]*`, not in `P.FNAMES`, `P.VNAMES`, `CMDS`, `ALIAS`, `MACROS`, not
`ans`; `theta` and `d` are allowed.

## Deviations from DESIGN.md (and why)

1. **Live pins cover the whole `DEPS` closure**, not just the family (§18.4 sketch). A
   suspended generator reaches its module's dependencies through `R.MODS[...]`; pinning only
   the family let a nested `need` evict, say, `poly` under a suspended `g_parts`. `NEEDED`
   slots still hold family keys; `LIVE` counts each closure member (with multiplicity).
2. **`need` never evicts a member of the closure it is loading** (stamped `USE == now`).
   Without this, loading `solve` could evict the `poly` it had just loaded.
3. **Stores are refused when the stored text would name its own variable** (`x+1=>x`,
   `b=c` with `c = b+1`): new message `circular definition`. Otherwise stage 6 would expand
   forever (capped at `definition too deeply nested` on every later use).
4. **`F_DEG` record flag** (new): HIST entries have no angle slot, and F4 must re-parse in
   the entry's mode. A form job's ctx is `[1 if F_DEG else 0, None, 0, 1]`.
5. **`start` returns `(None, message)`** for purge and definitions; `go` makes the message
   record without starting the trampoline.
6. **`theta` is a valid variable name** (§7.9 excludes VALUE words, but the `F_PURGEHINT`
   list names `theta`).
7. **Autoclose follows FlowCE exactly:** a mismatched closer or more than 64 open brackets
   leaves the line as typed (rpn reports it). More than 8 `ans()`: `too many ans()`.
8. **Budget message** is `too long` (§10.5's list). `RuntimeError` gives `Expression too
   complex` (§16.10); `MAXGEN` gives node's `expression too complex`.
9. `DEPS['form'] = ('norm', 'fact')` (new; CVFORM needs simplify, together, factor, expand).

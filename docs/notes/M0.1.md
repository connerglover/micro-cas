# M0.1: Test harness (notes)

Files: `pytest.ini`, `tests/conftest.py`, `tests/support/{evodepth,lint,framelint,invariants,gen}.py`,
`tests/depth_shapes/{probe4_shapes,probe6_shapes,levels_shapes}.py`,
`tests/test_depth_calibration.py`, `tests/test_lint.py`, `tests/test_framelint.py`.
The self-tests of `invariants.py` and `gen.py` live in `test_lint.py`, because the §21.3 row

`python -m pytest` from the repo root finds `tests/` (`testpaths`). `tests/` has no
`__init__.py`, so test file basenames must be unique. `pytest.ini` adds `--strict-markers` (a
mistyped marker is an error) and `-p pytester`.

## Using the harness (downstream tasks)

Every test's call phase already runs under the depth checker. You do not need to do anything
for that.

- **Depth model.** A src function called directly from a test runs at its **declared level**
  (automatic base). So `K.add_` called from a test runs at 6 and `mk` under it at 7. A frame
  that runs deeper than its `#@L` level fails the test, and so does any depth over 8.
  Generators driven by `R.go`'s `send` cost no frame (`gen_penalty = 0`; PROBE6 is assumed to
  pass).
- **Markers.**
  - `@pytest.mark.device_base(n)`: root src frames start at `n+1` instead of their level.
  - `strict_depth` (or `--strict-depth` for the whole suite): every penalty is 1 and only the
    budget of 8 is checked. T1.13 runs the full suite this way.
  - `no_depth`: no checker.
  - `slow`, `oracle`.
  - `bundled`: the test runs only with `--bundled`.
  - `no_invariants`, `invariants_skip('special', ...)`: skip all or some invariant checks. The
    names are in `invariants.CHECKS`; `'base'` skips the `K.NN == K.BASE` check.
  - `allow_internal_error`: the test expects an `internal error` record from `R.go`.
- **The `evodepth` fixture.** `r, depth, stack = evodepth.measure(fn, *args)` gives the max
  device depth of one call. Use it for the nesting-invariance test (§20.7). `evodepth.max_depth`
  and `evodepth.checker` give the whole test's numbers.
- **The `update_golden` fixture** is True with `--update-golden`.
- **After each passing test** conftest checks:
  - the invariant scan of `sys.modules['node']`;
  - `SIMPBUG == 0` in every loaded src module;
  - `K.NN == K.BASE` if the test called `run.go`. conftest wraps `run.go` during the test, which
    also lets it fail the test on any `internal error` record.

  For `keyscript.run` sessions, the same checks are registered in `keyscript.AFTER_RUN`. There
  the internal-error check looks for strings that start with `internal error` in `R.HIST`.
- **After every test** conftest:
  - zeroes `SIMPBUG`;
  - calls `K.reset()`, so node ids never survive a test (module- or class-scoped fixtures must
    not hold ids);
  - calls `keyscript.reset_shims()` if keyscript is loaded.
- **Native hooks.** Declare them `None` with `#@native` (see FRAMELINT below):
  - in `node.py`: `ESC = None  #@native`, `MEMFREE = None  #@native`;
  - in `run.py`: `MEMFREE = None  #@native` and `BUSY = None`. `BUSY` holds `U.busy`, so call it
    with `#@calls 2`.

  conftest fills any of these that is still `None` with desktop stand-ins: ESC returns False,
  MEMFREE returns 1 MiB, BUSY does nothing. Tests that need a cancel or low memory set their own
  with `monkeypatch`.
- **Optional, for T1.1: a scan at every reset.** If `node.py` defines `ONRESET = None  #@native`
  and `reset()` begins with `if ONRESET is not None: ONRESET()`, conftest scans the table
  before every reset during a test. That includes the reset at the end of each `R.go`. The
  post-test scan alone sees only what survives a test. Tests that inject faults mid-`keep` use
  `no_invariants`.

## FRAMELINT (`tests/support/framelint.py`)

Run it as `python tests/support/framelint.py [--report] [--levels OUT.json] [dir]`. The default
dir is `src/`. `test_framelint.py::test_src_framelint_clean` runs it per src file. It
implements §17.3, §10.2 and §4.2.

**Call resolution.** These forms resolve to a function, and get the `L(callee) > L(caller)`
check:

- same-module names;
- `ALIAS.f`, through the module's own `import x as Y`;
- `R.MODS['key'].f` and `R.need('key').f`;
- locals bound to those, for example `M = R.need('poly')`.

Runtime keys map to files through `framelint.KEYS`: `int` -> `integ`, `fact` -> `factor`, and
so on. A literal `DEV = {...}` in `run.py` overrides it.

These are *dynamic* calls, and need `#@calls k`:

- a call through a local or a parameter;
- `getattr(...)(...)`;
- `T[i](...)`;
- a call to a module-level variable that is not a def. `R.BUSY` is one.

Method calls on lists, dicts and strings are treated as native.

**Extensions** (the design does not specify these):

1. **`#@native`** on a module-level hook assignment means the hook holds a native function.
   Calling it costs no frame and needs no `#@calls`. Without this marker, `K.ESC()` would need
   `#@calls 8` from `mk` (L7).
2. **Virtual generator calls.** These are not frame edges, so they get no level check:
   - `yield g_x(...)`;
   - `yield scoped(g_x(...))`;
   - a dynamic call with `#@calls 2` in those positions, for example
     `yield scoped(getattr(M, name)(...))  #@calls 2` in `g_int`.

   `run.go` may call `g_*` directly. That is how it creates the root generator.
3. **The import graph** (§4.2 MUST):
   - module-level imports between src modules must be acyclic;
   - no module-level import of a lazy module (it must go through `R.need`/`R.MODS`).

   Residency comes from `lint.RESIDENT`.
4. **Other rules:**
   - no nested `def`/`class` inside functions;
   - function levels must be 1..7;
   - a function with no level (no `#@L` on its def and no module default on line 1) is an
     error;
   - a module-level table of functions needs `#@table k`, and a `g_*` may not go in a table.
5. **Module bodies.**
   - Allowed calls: builtins, native-module functions, and calls that create a same-module
     generator object. The last covers the design's `GEN = type(_g())`.
   - The entry module `casevo.py` is exempt. Its body is checked as a level-0 caller.

`--report` prints the longest declared chain per entry point. Today, on the miniature
design-sketch tree in `test_framelint.py`, the chain is
`7: 0 casevo.<module> > 1 run.go > 2 printer.record > 3 alg.nev > 7 alg.postorder`.

## Subset lint (`tests/support/lint.py`)

Run it as `python tests/support/lint.py [paths]`. It covers device-python §13 and the §17.4
bans. The **module map** lives here, and framelint imports it:

- `ALIASES` holds the fixed aliases. A part takes its family's alias plus B or C (`polyb` ->
  `POB`).
- `RESIDENT`, `UI_MODULES` (`ti_*` imports allowed) and `EXACT_MODULES` (`/` banned): a part
  counts as its family.
- `NATIVE_MODULES` lists the importable natives. An unknown import is an error.

Line markers: `#@unordered-ok` (dict or set iteration) and `#@float-ok` (`/` in an exact module,
`round`, `repr`, and `%e`/`%f`/`%g`).

These are banned beyond the design's list:

- `eval`, `exec`, `super`, `property`;
- `key=` in any call;
- decorators;
- dunder defs, and dunder attributes other than `__name__` and `__dict__`;
- `math.X` outside the CE list;
- `print(file=/flush=)`;
- `startswith` with a tuple;
- positional arguments after `*args`;
- `raise StopIteration` inside a generator.

## Deviations from DESIGN.md

- **Level table.** The checker reads levels from framelint in-process (`level_table(src)`),
  not from `build/levels.json`, because `build/` belongs to M0.4. `framelint.py --levels
  OUT.json` writes the same table (`{module: {function: level}}`). Under `--bundled`, conftest
  reads `dist/levels.json` if it exists. Otherwise it runs with no automatic base and no level
  assertion.
- **Penalties.** Default mode uses `gen_penalty 0`, `native_penalty 1` and `dunder_penalty 1`.
  The last two stay strict until PROBE5 reports. Strict mode sets `gen_penalty` to 1 as well.
- **`max_depth` counts the attempted frame.** It includes the frame that hit the emulated limit
  (11), as a budget violation. Calibration counts are unchanged.
- **GeneratorExit is not counted.** A `GeneratorExit` thrown into a dying generator (through
  `PY_THROW`) never counts or fails. Otherwise a generator garbage-collected inside a deep frame
  would look like an L2 frame running at depth 8.
- **The invariant scan is an independent reference** (§5.7 hash, §5.8 masks, the pair order by
  `(H, structural tie-break)`), not K's own functions. The exceptions are `K.negfirst` for the
  sign check and `K.reset` for cleanup.
  - Beyond §8.9 it also checks:
    - topology, uniqueness and bucket chains;
    - arity;
    - UNDEF inside ADD/MUL/functions;
    - the `mul_` rules 2 and 5-9;
    - the `fn_` special values (trig at kπ/12, `ln` of perfect powers or non-integers,
      inverse cancellation, functions of ±∞);
    - the `absn` rules (content and coefficient).
  - Radicands are checked exactly as far as `rootsplit` can reduce them (§6.2). For n > 10^12,
    partial reduction is accepted.
  - If T1.1 reads a rule differently, use `invariants_skip(...)` and ask the M0.1 owner to
    adjust.
- **`--bundled`** loads `build/manifest.py` (`MODULES`, `ENTRY`) and installs an import alias,
  so that `import node` loads `CVNODE`. It also points `keyscript` at `dist/device`. This is
  untested until T1.14.

## Known gaps

- `str()` of floats and `sum()` of floats are not detected (they cannot be typed statically).
- Dict/set iteration detection is heuristic. It catches names bound to `{}`, `set()`, `dict()`
  or displays (module globals and function locals), and `.keys/.values/.items`. It misses
  dicts that arrive as parameters.
- The FRAMELINT report treats every function with no incoming frame edge as an entry point.
  Generators are entered by the trampoline at depth 2. Their chains are listed separately, not
  joined under `run.go`.
- PROBE5/PROBE6 device numbers are not in yet. When they arrive, add them to
  `test_depth_calibration.py` and set the penalties to match (§20.2). The PROBE6 `ingen`
  expectation (6) is the design's assumption.

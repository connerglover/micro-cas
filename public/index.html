A smoother way in.

The installer selects every file and its location. Only the two launchers need to appear in your Python program list.

Prefer a manual install? Download the ZIP.
Why use two storage locations?

CASEVO and CVTEST are small source launchers, so they go to RAM and appear in Python. The libraries are compiled EVO modules (.8mp2), stored in archive and imported as needed. This avoids compiling the engine on the calculator. Imported code still needs working memory; archive is not extra RAM. Ordinary archived .py files are not a substitute.

My calculator isn’t in the list.

Turn it on and use a USB cable that supports data. Close TI Connect and other calculator tabs. In Chrome or Edge, select the TI-84 EVO serial port when prompted. This installer supports the EVO and EVO-T, not the TI-84 Plus CE.

A transfer stopped. What now?

Keep any files that arrived. Reconnect, then install again: the same cas-evo filenames are replaced. If you stopped the transfer yourself, choose Install again. If the connection timed out, reload this page first. Wait for archive verification before running CASEVO.

I already sent some files to RAM.

The installer moves old cas-evo companions to archive only when their contents match the previous source package. Modified files are preserved and reported for you to move manually. It then installs the compiled libraries and replaces the two launchers. Your other programs stay untouched.
